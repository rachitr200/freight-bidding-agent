Agent workflow

6-node LangGraph pipeline

Each node is independently testable. Conditional edges enforce fail-fast logic — no nested if/else chains. Click any node to expand.

01
validate_request

Pydantic validation catches bad input — missing destination, negative weight, unsupported cargo type — and returns a structured error immediately. No carrier calls are made until input is clean.

02
normalize_request

Assigns a request_id, derives the lane string (origin → destination), detects domestic vs. international, and classifies urgency from timeline_days: critical (1 day), urgent (2 days), standard (3+).

03
collect_rates

Queries all 5 Canadian mock carriers. Each quote is filtered by timeout threshold, weight limit, cargo type compatibility, and transit time. Timed-out or rejected carriers move to invalid_quotes with reasons.

04
llm_analyze_quotes Key differentiator

All valid quotes and shipment context are passed to OpenAI GPT-4o-mini. The model returns a recommended carrier, natural-language reasoning explaining the choice, risk flags, and a confidence score (0.0–1.0). Most freight tools skip this and just pick the cheapest rate.

05
select_best_quote

Uses the LLM recommendation when available. If the LLM call fails (timeout, rate limit, outage), falls back gracefully to the cheapest valid rate. The workflow always produces a result and never fails silently.

06
finalize_quote

Applies markup (10% standard, 5% preferred — env-variable driven, no code changes needed), sets a 24-hour expiry timestamp, attaches full LLM reasoning to the output payload, and returns the complete structured response.

Tech stack

Built with production patterns

Every architectural decision has a documented MVP → production upgrade path.

LangGraph
Workflow orchestration

Stateful 6-node graph. Orchestration is fully separated from business logic. Each node is independently testable. Conditional edges handle fail-fast routing without nested if/else.

OpenAI GPT-4o-mini
LLM reasoning node

Returns recommended carrier with natural-language reasoning, risk flags, and a 0–1 confidence score. Pluggable — swap for Claude, Gemini, or a local model via the config.

FastAPI
REST API server

Async-native. Exposes /api/quote (POST) and /api/health (GET). Production upgrade: add JWT auth middleware and webhook callbacks for quote delivery.

Pydantic
Schema validation

Validates every request before any carrier call is made. Structured field-level error messages. Eliminates an entire class of runtime bugs upstream.

Python 3.11+
Core language

Full type annotations throughout. asyncio-ready for parallel carrier calls in production — changes O(n) sequential latency to O(1) with a single refactor.

Redis + Postgres
Production data layer

Planned upgrade. Redis for 15-minute rate caching on repeat lanes. Postgres for persistent quote history, audit logs, and historical lane pricing fed into the LLM prompt.
